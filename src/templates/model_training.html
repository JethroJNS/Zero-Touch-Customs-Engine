Petunjuk Training Ulang

Format Dataset

Setiap shipment harus dalam folder terpisah dengan format berikut:

training_dataset/
{No. AJU}/
{No. AJU}_CI.pdf  # Commercial Invoice
{No. AJU}_PL.pdf  # Packing List
{No. AJU}_BL.pdf  # Bill of Lading
{No. AJU}.xlsx   # Ground Truth CEISA Excel

Cara Menambahkan Dataset

  1. Siapkan folder shipment dengan 4 file: CI, PL, BL, dan XLSX
  2. Tekan tombol Tambah Dataset di atas
  3. Pilih folder yang berisi file-file shipment (4 file: CI, PL, BL, XLSX)
  4. Sistem akan otomatis mendeteksi dan menambahkan ke training set

Cara Melakukan Training

  1. Pastikan dataset sudah lengkap (CI + PL + BL + XLSX)
  2. Tekan tombol Retrain Model
  3. Training akan berjalan di background (bisa menutup halaman)
  4. Model baru akan otomatis menggantikan model lama setelah training selesai

Parameter Training

Training menggunakan parameter optimal:

Epochs: 40 (dengan early stopping)
Learning Rate: 2e-5
Batch Size: 4
Entity Weight: 5.0
O Weight: 0.1
Train/Val Split: 80/20
Patience: 10 epochs

Perhatian: Training model membutuhkan waktu 1-2 jam tergantung jumlah dataset dan spesifikasi hardware. Pastikan laptop/PC tidak dalam mode sleep selama training.

Tambah Dataset Baru

Pilih file CI, PL, BL (PDF) dan data (XLSX) untuk satu shipment.
